# Contributing to Elegant Sounds

Thank you for considering contributing to Elegant Sounds! 🎧

## How to Contribute

1. **Fork the repository**  
   Click the "Fork" button at the top right of this page to create your own copy.

2. **Clone your fork locally**

   ```bash
   git clone https://github.com/Epic2077/elegant-sounds.git
   cd elegant-sounds
   ```

3. **Create a new branch**

   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes**

   - Follow the code style and conventions used in the project.
   - Write clear, concise commit messages.

5. **Test your changes**

   - Make sure your changes do not break existing functionality.
   - Run `npm run dev` and check your feature locally.

6. **Push to your fork**

   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**
   - Go to the original repository and click "Compare & pull request".
   - Fill out the PR template and describe your changes.

## Code of Conduct

Please be respectful and considerate in your interactions. See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) if available.

## Reporting Bugs & Suggesting Features

- Use [GitHub Issues](https://github.com/Epic2077/elegant-sounds/issues) to report bugs or suggest features.
- Please use the provided issue templates.

## Style Guide

- Use TypeScript for all code.
- Use Prettier and ESLint for formatting and linting.
- Write clear and descriptive comments where necessary.

## Need Help?

If you have questions, open an issue or contact the maintainers.

Happy coding! 🚀
